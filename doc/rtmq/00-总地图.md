## 1. 必嗨 IM 里 RTMQ 站在哪

```mermaid
flowchart TB
  subgraph clients["各进程内的 RTMQ Proxy（客户端库）"]
    WS["websocket<br/>Go Proxy"]
    USR["usrsvr<br/>Go Proxy"]
    MSG["msgsvr<br/>Go Proxy"]
    FRW["frwder<br/>C Proxy x2"]
  end

  subgraph server["RTMQ Server 中心（C，通常与 frwder 同栈）"]
    direction TB
    LSN["07 listen<br/>accept"]
    RSVR["10-11 rsvr<br/>连接/收发包"]
    DIST["08 dist<br/>按 nid"]
    WRK["12 worker<br/>reg 回调"]
    SUB["09 sub<br/>publish 查表"]
  end

  WS -->|TCP| RSVR
  USR -->|TCP| RSVR
  MSG -->|TCP| RSVR
  FRW -->|TCP| RSVR
  LSN --> RSVR
  DIST --> RSVR
  RSVR --> WRK
  SUB --> RSVR

  WS -.->|reg 回调| FRW2["frwder handler\npublish/async_send"]
  FRW -.-> FRW2
```

**记忆口诀**：每个进程一个 **Proxy**；中心一个 **Server**；**publish 广播 type**，**async_send 单播 nid**。

## 3. 两条业务主线（整库就这两条路）

### 3.1 上行：接入 → 业务（publish）

以 **websocket 收到 IM 帧 → usrsvr 处理** 为例：

```mermaid
sequenceDiagram
  participant App as websocket 进程
  participant P1 as Proxy 13-16
  participant S as Server 10-11
  participant W as Server worker 12
  participant P2 as usrsvr Proxy
  participant Biz as usrsvr reg 回调

  App->>P1: reg 回调里 async_send(IM帧)
  P1->>S: TCP RTMQ 包
  Note over S: 08 dist 通常不参与<br/>（对端已 SUB）
  S->>W: recvq 完整帧
  W->>P2: publish(type) 推到所有 SUB 连接
  P2->>Biz: proxy worker reg(type)
```

**涉及文档**：13→14/15→10/11→12→09(查 SUB 表)→16→17

---

### 3.2 下行：业务 → 指定接入 NID（async_send）

以 **msgsvr fan-out → websocket:8002** 为例：

```mermaid
sequenceDiagram
  participant Biz as msgsvr reg 侧
  participant P1 as msgsvr Proxy 13
  participant D as dist 08
  participant R as rsvr 10-11
  participant P2 as websocket Proxy 13-16
  participant WS as websocket fan-out

  Biz->>P1: async_send(type, nid, IM帧)
  P1->>D: distq + DIST_REQ
  D->>R: 按 nid 选 rsvr 线程
  R->>P2: TCP writev
  P2->>WS: proxy worker reg
```

**涉及文档**：06(async_send)→13→08→10/11→14/15→16
