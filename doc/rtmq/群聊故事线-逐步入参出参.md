# 群聊故事线 · 逐步入参出参（uid=100001）

> **主角**：100001 @ ws-1 NID=**20001** · 示例 sid=**900001** · cid=**1001** · 首群 gid=**1**  
> **配套**：[群聊故事线-单用户对照17篇.md](群聊故事线-单用户对照17篇.md) · [群聊10人5接入-RTMQ逐步标注手册.md](群聊10人5接入-RTMQ逐步标注手册.md)  
> **表格列**：**入参** = 本步消费的数据 · **出参** = 本步产生/写出的数据 · **—** = 该层无结构化入出参

---

## 0. 两层数据壳（先背这个，后面每步都套它）

### 0.1 有 RTMQ 的业务包 = RTMQ 头 + IM 帧

```text
┌─ RTMQ 层（02 mesg · rtmq_header_t / Go RtmqHeader）──────────────┐
│ type=IM的cmd(如0x0101)  nid=源或目的NID  flag=1(RTMQ_EXP_MESG)      │
│ length=52+pb_len       chksum=0x1FE23DC4                            │
├─ IM 层（comm/mesg.go · MesgHeader 52B + protobuf）─────────────────┤
│ Cmd Length Sid Cid Nid Seq Dsid Dseq                                │
│ + body: MesgOnline / MesgGroupChat / …（mesg.pb.go）                 │
└─────────────────────────────────────────────────────────────────────┘
```

| 结构体 | 源码 | 关键字段 |
|--------|------|----------|
| `rtmq_header_t` | `rtmq_mesg.h` / `RtmqHeader` | `type, nid, flag, length, chksum` |
| `MesgHeader` | `comm/mesg.go` | `Cmd, Length, Sid, Cid, Nid, Seq, Dsid, Dseq` |
| Proxy 回调 **16/17** | `RtmqRegCb` | 入参 `data` = **IM 整帧**（已剥 RTMQ 头），`cmd`=IM cmd |

### 0.2 无 RTMQ 的几类数据

| 类型 | 结构 | 源码 |
|------|------|------|
| HTTP JSON | `UsrSvrRegisterRsp` / `IpListRsp` | `register.go` / `iplist.go` |
| Redis 键 | `im:sid:*` / `chat:gid:*` | `comm/key.go` |
| 进程内 | `ImGroup` map `(gid→sid→cid)` | `chat_tab/chat.go` |

### 0.3 RTMQ 系统包（启动 P-auth / P-sub）

| 包 | flag | type | body |
|----|------|------|------|
| AUTH_REQ | 0 SYS | 0x0001 | `usr, passwd, nid`（配置里 Id=20001/30000/31000） |
| AUTH_ACK | 0 SYS | 0x0002 | 鉴权结果 |
| SUB_REQ | 0 SYS | 0x0005 | `{ cmd: 0x0101 }` 等已 Register 的 IM cmd |
| SUB_ACK | 0 SYS | 0x0006 | — |
| publish 路径 | 1 EXP | =IM cmd | 整段 IM 帧 |
| async_send 路径 | 1 EXP | =IM cmd | 整段 IM 帧；**IM头.Nid=目标接入 NID** |

## 2. 阶段 1：注册 + iplist（⚪ 无 RTMQ）

### 2.1 HTTP 注册

| 步 | 协议 | 入参 | 出参 |
|----|------|------|------|
| B1 `GET /im/register` | HTTP Query | `uid=100001, nation=1, city=1, town=1` | JSON **`UsrSvrRegisterRsp`**：`{uid, sid, nation, city, town, code, errmsg}` |
| 内部 | Thrift seqsvr | — | **`sid=900001`**（示例，实际 seqsvr 分配） |

```json
{"uid":100001,"sid":900001,"nation":1,"city":1,"town":1,"code":0,"errmsg":"OK"}
```

⚪ **无** MySQL 写回包字段以外的 RTMQ/IM 结构。

### 2.2 HTTP iplist

| 步 | 入参 | 出参 |
|----|------|------|
| B2 `GET /im/iplist` | Query：`uid, sid, type=2(WS), clientip` | JSON **`IpListRsp`** |

```json
{
  "uid": 100001,
  "sid": 900001,
  "type": 2,
  "token": "<加密串>",
  "expire": 86400,
  "len": 1,
  "list": ["ws://host:8002/im"],
  "code": 0,
  "errmsg": "OK"
}
```

| 字段 | 含义 | 后续用在哪 |
|------|------|------------|
| `token` | 明文格式 `uid:100001:ttl:…:sid:900001:end` 再加密 | ONLINE 的 **`MesgOnline.token`** |
| `list[0]` | ws 地址 | 浏览器连 ws-1 |

## 3. 阶段 2：WebSocket + ONLINE

### 3.1 WS 握手（⚪）

| 步 | 入参 | 出参 |
|----|------|------|
| B3 | TCP + WS URL `/im` | 连接对象 **`LsndConnExtra`**：`cid=1001`, status=READY |

### 3.2 浏览器 → ws-1 上行 ONLINE（⚪→🟢）

**浏览器发出（WS 二进制 = IM 帧，无 RTMQ 头）**

| 层 | 入参 |
|----|------|
| **MesgHeader** | `Cmd=0x0101, Sid=900001(会话), Cid=0(尚未分配), Nid=0, Length=pb_len` |
| **MesgOnline** (pb) | `uid=100001, sid=900001, token=<iplist.token>, app, version, terminal` |

| 步 | 组件 | 入参 | 出参 | RTMQ |
|----|------|------|------|------|
| B4 | 浏览器 | 上表 IM 帧 | — | 无 |
| B5 | `LsndMesgOnlineHandler` | IM 帧 | 补 **`head.Cid=1001`, `head.Nid=20001`** | 无 |
| B6 | **P-send** `AsyncSend(0x0101, buf)` | IM 帧（已补 cid/nid） | RTMQ 包：`RtmqHeader{type=0x0101,nid=20001,flag=1}+IM帧` | Proxy |

### 3.3 FORWARD → usrsvr（🟢 publish）

| 步 | 组件 | 入参 | 出参 | 17篇 |
|----|------|------|------|------|
| B7-B8 | FORWARD rsvr + frwd | RTMQ 包 | **S-pub(0x0101)** 查 **09** → nid 30000 | **10** **12** **06** **09** |
| B9 | **16** `UsrSvrOnlineHandler` | `cmd=0x0101, nid=20001, data=IM帧` | 解析 **`head+MesgOnline`** | **16** **17** |

**usrsvr 业务入参（handler 内）**

```text
head: Sid=900001, Cid=1001, Nid=20001
req:  uid=100001, sid=900001, token=…
```

### 3.4 Redis + seqsvr（⚪）

| 步 | 入参 | 出参（Redis 写） |
|----|------|------------------|
| B10 | sid, uid, cid, nid | `ZADD im:sid:zset` · `ZADD im:uid:zset` · `HMSET im:sid:900001:attr {CID,UID,NID}` · `SADD im:uid:100001:to:sid:set 900001` |
| seqsvr | sid | **`seq=50001`**（示例）→ 写入 ONLINE_ACK |

### 3.5 usrsvr → ws-1 下行 ONLINE_ACK（🟢 unicast）

**usrsvr 构造出参**

| 层 | 出参 |
|----|------|
| **MesgHeader** | `Cmd=0x0102, Sid/Cid/Nid/Seq` **保留请求 head** |
| **MesgOnlineAck** (pb) | `uid=100001, sid=900001, seq=50001, code=0, errmsg=Ok, app, version, terminal` |

| 步 | 组件 | 入参 | 出参 | 17篇 |
|----|------|------|------|------|
| B11 | P-send ACK | 上表 IM 帧 | RTMQ EXP type=0x0102 | **13** |
| B12 | **S-unicast** | IM 帧 + **目标 nid=20001** | dist→FORWARD→ws-1 | **06** **08** **11** |
| B13 | **16** `LsndUpMesgOnlineAckHandler` | IM 帧 | 连接 status=**LOGIN**；可选推浏览器 WS | **16** |
| B14 | 浏览器 | WS 帧 | 收到 **MesgOnlineAck** | 无 RTMQ |

## 4. 阶段 3：100001 建群 GROUP-CREAT

### 4.1 浏览器上行

| 层 | 入参（100001 发出） |
|----|---------------------|
| **MesgHeader** | `Cmd=0x0301, Sid=900001, Cid=1001, Nid=20001` |
| **MesgGroupCreat** (pb) | `uid=100001, gid=0(忽略), name="demo群", desc="…"` |

### 4.2 RTMQ 上行链

| 步 | 组件 | 入参 | 出参 | RTMQ |
|----|------|------|------|------|
| C1 | 浏览器 | 上表 IM 帧 | — | 无 |
| C2 | P-send | IM 帧 | RTMQ EXP **0x0301** | Proxy |
| C3 | publish | RTMQ 包 | **09** 命中 usrsvr 30000 | Server |
| C4 | **16** `UsrSvrGroupCreatHandler` | `head+MesgGroupCreat` | 见下 Redis | Proxy+Server |

**usrsvr 业务出参（Redis）**

| 操作 | 键 / 值 |
|------|---------|
| INCR | `chat:gid:incr` → **`gid=1`** |
| GroupRegister | `chat:gid:zset` · `chat:gid:1:role` owner=100001 · `chat:gid:1:info` · `chat:uid:100001:to:gid` |
| GroupJoinOnline | `chat:gid:1:to:nid:zset` **+20001** · `to:uid` · `to:sid` · role member |

### 4.3 下行 ACK + ImGroup

**usrsvr 出参 IM 帧**

| 层 | 出参 |
|----|------|
| **MesgHeader** | 保留请求 sid/cid/nid/seq，`Cmd=0x0302` |
| **MesgGroupCreatAck** (pb) | `code=0, errmsg="Ok:1"` ← **gid 在 errmsg 里** |

| 步 | 组件 | 入参 | 出参 | RTMQ |
|----|------|------|------|------|
| C5 | P-send ACK | 上表 | RTMQ **0x0302** | Proxy |
| C6 | S-unicast | nid=**20001** | → ws-1 | Server **08** |
| C7 | **16** `LsndUpMesgGroupMemberAckHandler` | ACK IM 帧 | **`ImGroupJoin(gid=1, sid=900001, cid=1001)`** + 推浏览器 WS | Proxy |
| C7b | ImGroup（⚪） | gid,sid,cid | 进程内 map 登记 | 无 |

## 5. 阶段 4：100002～100010 加群

### 5.1 单人 JOIN（以 100003 @ ws-2 NID=20002 为例）

**上行入参**

| 层 | 字段 |
|----|------|
| **MesgHeader** | `Cmd=0x0305, Sid=900003, Cid=…, Nid=20002` |
| **MesgGroupJoin** (pb) | `uid=100003, gid=1` |

**usrsvr 出参**

| 类型 | 出参 |
|------|------|
| ACK IM | `MesgGroupJoinAck{code=0, errmsg="Ok:1"}` → **unicast nid=20002** |
| Redis | `chat:gid:1:to:nid:zset` **+20002** 等同 CREAT |
| NTF pb | **`MesgGroupJoinNtf{uid=100003, gid=1}`** |

### 5.2 JOIN_NTF fan-out（🟢 5× unicast）

| 步 | 入参 | 出参 | RTMQ |
|----|------|------|------|
| groupBroadcast | Redis **`GroupGetGidToNidSet(gid=1)`** → `[20001..20005]` | 每个 nid 一包：`MesgHeader{Nid=目标nid, Cmd=0x0350}+MesgGroupJoinNtf` | **5× AsyncSend** |
| ws 各 Pod | RTMQ 下行 | **16** `LsndUpMesgGroupNtfHandler` → **TravImGroupSession(gid)** → 已 ImGroupJoin 的连接收 WS | Proxy+⚪ |

**10 人加群完成后 Redis 快照**

```text
chat:gid:1:to:nid:zset  → {20001,20002,20003,20004,20005}
chat:gid:1:to:uid:zset  → {100001..100010}
```

## 6. 阶段 5：100001 发群消息 + 两段 fan-out

### 6.1 上行 GROUP-CHAT

**浏览器 / ws-1 入参**

| 层 | 示例值 |
|----|--------|
| **MesgHeader** | `Cmd=0x030B, Sid=900001, Cid=1001, Nid=20001, Seq=…` |
| **MesgGroupChat** (pb) | `uid=100001, gid=1, text="大家好", time=…, level=0` |

| 步 | 组件 | 入参 | 出参 | RTMQ |
|----|------|------|------|------|
| D1-D2 | ws-1 | IM 帧 | — | 无 |
| D3-D6 | publish 链 | IM 帧 | **16** `MsgSvrGroupChatHandler(head, MesgGroupChat, raw)` | 1× pub |

**msgsvr handler 入参 / 侧效应**

| 入参 | 侧效应出参 |
|------|------------|
| `head+req` | Redis 校验 **GroupGetRole(gid=1, uid=100001)** |
| `raw` 全帧 | 异步 chan → **Mongo 落库**（⚪） |
| — | 读 **`GroupGetGidToNidSet(gid=1)`** → `[20001,20002,20003,20004,20005]` |

### 6.2 第一段 fan-out（🟢 RTMQ ×5）

**msgsvr 每次 `send_data` 入参 / 出参**

```go
// send_data(cmd, sid, cid, nid, seq, body, length)
send_data(
  CMD_GROUP_CHAT,     // 0x030B
  head.Sid,           // 900001 发言者 sid
  0,                  // cid=0
  20001..20005,       // ★ 目标接入 NID，循环 5 次
  head.Seq,
  data[MESG_HEAD_SIZE:],  // ★ 原始 MesgGroupChat pb（不含 IM 头）
  head.Length,
)
```

**每次循环出参（IM 帧，经 RTMQ async_send）**

| 层 | 出参 |
|----|------|
| **MesgHeader** | `Cmd=0x030B, Sid=900001, Cid=0, Nid=2000x(目标Pod), Seq=原seq, Length=pb_len` |
| **body** | 同一条 **MesgGroupChat** pb |

| 步 | RTMQ 包数 | 17篇 |
|----|-----------|------|
| D9-D11 | **5×** unicast | **06→08→11→16** |

### 6.3 第二段 fan-out（⚪ ImGroup ×10 浏览器）

| 步 | 组件 | 入参 | 出参 |
|----|------|------|------|
| D12 | ws 各 Pod **16** `LsndUpMesgGroupChatHandler` | 完整 IM 帧（含 MesgGroupChat） | — |
| D13 | **TravImGroupSession(gid=1)** | `gid=1` | 对每个 `(sid,cid)` 若 `imGroup[1]==true` → **WS write 同一 IM 帧** |
| D14 | 浏览器 | — | ws-1：**100001+100002** 各 1 份；ws-2：**100003+100004** … 共 **10** 份 |

### 6.4 GROUP-CHAT_ACK（🟢 1× unicast → 发言者）

| 层 | 出参 |
|----|------|
| **MesgHeader** | 保留上行 sid/cid/nid/seq，`Cmd=0x030C` |
| **MesgGroupChatAck** (pb) | `code=0, errmsg=Ok` |

| 步 | 入参 | 出参 | RTMQ |
|----|------|------|------|
| D15 | 发言 head | unicast **nid=20001** | 1 包 |

### 6.5 本条消息数据总账

| 指标 | 值 |
|------|-----|
| RTMQ 业务包 | **7**（1 pub + 5 fan-out + 1 ACK） |
| 浏览器收 CHAT | **10**（ImGroup，非 RTMQ） |

## 7. 阶段 6：退群 / 下线（入参出参要点）

### 7.1 GROUP-QUIT（100001）

| 上行入参 | 出参 |
|----------|------|
| `MesgGroupQuit{uid,gid}` + head | ACK `MesgGroupQuitAck` → unicast 20001 |
| — | Redis 删成员；可选 QUIT_NTF 5× unicast |
| ws **16** | `ImGroupQuit(gid,sid,cid)` ⚪ |

⚪ **无** RTMQ unsub；**无** 单独退订 API。

### 7.2 停 ws-1 Pod

| 入参 | 出参 |
|------|------|
| 进程 SIGTERM / TCP 断 | FORWARD **09** 删 `(cmd, 20001)` 全部条目 |
| 此后 async_send(nid=20001) | **失败**（无连接） |

### 7.3 停 msgsvr / usrsvr / frwder

| 顺序 | 入参 | 出参 |
|------|------|------|
| msgsvr 停 | TCP 断 | BACKEND 删 **31000**；publish GROUP_CHAT 无订阅者 |
| usrsvr 停 | TCP 断 | BACKEND 删 **30000** |
| frwder 停 | — | 28888/28889 listen 结束；所有 Proxy **P-conn** 断 |
